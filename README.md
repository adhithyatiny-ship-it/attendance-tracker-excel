# Attendance Tracker Excel

## Overview
This is a simple Excel-based Attendance Tracker designed to record and track student attendance. It demonstrates data cleaning, organization, and visualization using Excel features like PivotTables and charts.

## Features
- Records student attendance by date, name, department, and status (Present/Absent)
- Cleans raw data for consistent formatting
- Uses a flag system (1 for Present, 0 for Absent) for calculations
- Calculates total students, total present, and attendance percentage
- Visualizes attendance using bar charts

## How to Use
1. Open `attendance_tracker.xlsx` in Microsoft Excel.
2. Enter the raw attendance data in the "Raw Data" sheet.
3. The cleaned data and calculations will automatically update in the "Cleaned Data" sheet.
4. Check the PivotTable and charts to analyze attendance by student or department.
